# QuickPane 3.12.0.1 (fork)

QuickPane 3.12.0.1 uses far less memory when you have many pinned folders, and it rebuilds the pane far faster. It also adds a What's new card to the About page and tidies two settings pages. This is the first release that people on 3.12.0.0 hear about through the update notice.

## At a glance

| Change | What you will notice | Tracked in |
|---|---|---|
| Lighter with many pins | Less memory and shorter pauses when a pane rebuilds. The difference is large with hundreds of pins and small with a few dozen. | [#210](https://github.com/prisant-labs/windows-explorer-quickpane/issues/210) |
| What's new on About | A short summary of this version, with a link to its full notes. | [#208](https://github.com/prisant-labs/windows-explorer-quickpane/issues/208) |
| Clearer settings rows | Pane sections and Quick actions rows have their own icons, an info button, and more room around the switch. | [#202](https://github.com/prisant-labs/windows-explorer-quickpane/issues/202), [#203](https://github.com/prisant-labs/windows-explorer-quickpane/issues/203), [#205](https://github.com/prisant-labs/windows-explorer-quickpane/issues/205), [#207](https://github.com/prisant-labs/windows-explorer-quickpane/issues/207) |
| Remote drives | The SSH section uses one name everywhere. | [#204](https://github.com/prisant-labs/windows-explorer-quickpane/issues/204) |
| Backup & restore | The card stays at its own height. | [#201](https://github.com/prisant-labs/windows-explorer-quickpane/issues/201) |

## Added

**What's new on About.** The About page has a card that summarizes the version you are running, with a link to its full release notes. The summary ships inside the program, so it adds no network request. The row that opens the whole changelog is now called Changelog.

## Changed

**A pinned folder's right-click menu is built when it opens.** Every pinned row used to build its whole menu when the pane built, in every pane, whether or not anyone opened it. The menu looks and works as before.

These are Windows Sandbox measurements with invented folders. Each row compares the two builds in the same job.

| Pins, windows, Quick actions section | Private memory, 3.12.0.0 to this build | Pause after one rename, 3.12.0.0 to this build |
|---|---|---|
| 508, 3, off | 410 MB to 118 MB | 3.3 to 4.0 s, to about 0.6 s |
| 508, 3, on | 567 MB to 107 MB | 5.4 to 10.0 s, to about 0.75 s |
| 58, 3, off | 77 MB to 50 MB | under 0.2 s on both |

The samples include some memory waiting for cleanup, so a difference of about 10 MB is noise. Opening a menu takes about the same time as before.

**Settings rows.**

- Each row on the Pane sections page has its own icon. They all shared one list icon, which looked like the drag grip beside it (#207).
- Rows on the Pane sections and Quick actions pages have an info button beside the label. Its tooltip says what the row is, and for a section, when it does not appear. The button works from the keyboard and with a screen reader. Built-in quick actions move their description there, so their rows are shorter (#205).

**Remote drives.** The SSH section is now called Remote drives on the Pane sections page, in the pane's section header, and in its row menu, the same as its Settings page. A header you renamed keeps your name (#204).

## Fixed

- The Backup & restore card in Settings stays at its own height. It stretched to fill the page, with its icon at the top and its buttons in the middle (#201).
- Rows on the Quick actions settings page show the same icon as their row in the pane, instead of a blank gap (#202).
- On the Pane sections and Quick actions settings pages, the on/off switch has more room from the Move buttons (#203).

## Still open

- **#148 (QuickPane exits after an Explorer restart)** stays open until a desktop run restarts Explorer and QuickPane keeps running.
- **#199 (the automatic update check can run late)** still applies. The check can wait until the cursor next moves, so a notice is delayed and not lost.
- **#177 (dock height as a share of the monitor)** is the part of that issue still open.
- **#160 (the dock after a monitor's scaling changes)** is unconfirmed. It needs two monitors at different scales.
- **Testing.** The Settings changes and the What's new card ran on a real desktop before this release. The pin menu change was checked in Windows Sandbox and by unit tests only. The Sandbox did not cover opening a pin's menu from the keyboard, or the desktop dock's auto-hide while a menu is open.

## For developers

- `LazyContextMenu` builds a row's menu on open. Other row menus, such as Recent and subfolder rows, are still built in advance and could use it later.
- An edit made inside QuickPane still rebuilds the pane twice, once from the edit's own scan and once from the file watcher. After this release, that costs far less.
- The test suite now has 797 tests.
- Release `QuickPane.exe`: about 1.07 MB.

## Install

Download `QuickPane-3.12.0.1-x64-setup.exe` and run it. It installs for the current user, with no administrator rights. Over an existing QuickPane, including one installed by the original project's installer, it closes QuickPane, replaces the program, and updates the same Add/Remove Programs entry. Your settings, groups, and pins in `%APPDATA%QuickPane` stay where they are.

The zip holds the same program, for replacing the files by hand instead:

1. Close QuickPane, and wait for it to finish: `Start-Process "$env:LOCALAPPDATA\QuickPane\QuickPane.exe" -ArgumentList '--exit' -Wait`
2. Keep a copy of the current `QuickPane.exe` in `%LOCALAPPDATA%\QuickPane`, so you can go back.
3. Unzip the download, and copy `QuickPane.exe` and `QuickPane.exe.config` into `%LOCALAPPDATA%\QuickPane`, replacing the files there.
4. Start `%LOCALAPPDATA%\QuickPane\QuickPane.exe` again.

`SHA256SUMS.txt` lists the SHA-256 hash of the installer, the zip, and each file inside the zip. The files are not code-signed, so Windows SmartScreen may warn before the installer first runs. This release also carries a GitHub build provenance attestation, which `gh attestation verify <file> -R prisant-labs/windows-explorer-quickpane` checks.
