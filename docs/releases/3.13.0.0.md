# QuickPane 3.13.0.0 (fork)

QuickPane 3.13.0.0 adds a quick switcher, a keyboard shortcut that finds a pin, a Recent folder, a drive, or a quick action from one search box. Recent gains folders it never shows and a Clear Recent button. The installer now runs on Windows 11 on Arm. Both new features start in a state that changes nothing until you use them.

## Added

**Quick switcher.** Turn on "Let a keyboard shortcut open the quick switcher" under Settings, Keyboard. The shortcut is Ctrl+Alt+Space unless you change it in the box below the switch. It opens a search box over the window in front.

- With nothing typed, the box lists your pins and Recent folders. Typing narrows the list to pins, Recent folders, drives, and quick actions that match every word you type. A match at the start of a name ranks first.
- Up and Down choose a row. Enter sends the Explorer window or the Open or Save dialog in front to that folder, and focus goes back to that window. Escape closes the box.
- Over an Explorer window, a quick action such as Copy path runs against that window's folder and selection. Over a file dialog, the box offers no quick actions.
- Over any other window, Enter opens the folder in a new Explorer window.
- Each result reports itself to screen readers as a list item, and the row Enter would choose is marked as selected.

**Folders Recent never shows.** A Recent row's right-click menu has "Never show this folder", or "Never show this file's folder" on a file. Recent then neither shows nor records that folder or anything inside it. The Recent page in Settings lists these folders, adds one through the folder picker, and shows one again. The list is shared by every profile.

**Clear Recent.** The Recent page in Settings has a Clear Recent button. It empties the Recent section and QuickPane's own Recent file. Windows' own Recent list and Quick Access keep their items, and Recent skips the Windows entries made before the clear. A folder you open again after the clear shows again.

**Trace events for diagnosing stalls.** A performance trace recorded with Windows Performance Recorder or PerfView now shows when QuickPane's background jobs, pane rebuilds, and calls into Explorer start and end. QuickPane writes these events only while someone on the same computer records a trace. They never leave the computer, and they hold no folder or file names. `docs/DEVELOPMENT.md` describes how to record one ([#219](https://github.com/prisant-labs/windows-explorer-quickpane/issues/219)).

## Changed

- The "Recent apps" page in Settings is now called "Recent". The new Recent folders controls sit above the Recent apps choice (#224).
- Changing the Recents count refreshes Recent at once, instead of at its next scan (#224).

## Fixed

- A custom command whose program ended in a dot or a space, such as `cmd.exe.` or `run.bat.`, got past the check that refuses Command Prompt, batch files, and other programs that read a folder name as code. Windows drops those trailing characters when it opens a file, so the command still ran Command Prompt. The check now reads the program name the way Windows opens it (#222).
- The installer runs on Windows 11 on Arm, which runs QuickPane's x64 build through emulation. It refused those computers before (#215).

## Still open

- **#148 (QuickPane exits after an Explorer restart)** stays open until a desktop run restarts Explorer and QuickPane keeps running.
- **#177 (dock height as a share of the monitor)** is the part of that issue still open.
- **#160 (the dock after a monitor's scaling changes)** is unconfirmed. It needs two monitors at different scales.
- **#132 (publish releases to winget)** waits on a decision about how to submit releases.
- **Testing.** The quick switcher and the Recent controls were checked in Windows Sandbox with invented folders, and by unit tests. They have not yet run on a real desktop. Nobody has tried the quick switcher with Narrator, over an Open dialog in another program, or with hundreds of pins; a unit test covers the ranking speed instead. Nobody has run QuickPane on an Arm computer, so how well it works there is untested. No trace has been recorded with the new events outside a unit test.

## For developers

- `PerfTrace` is an `EventSource` named "QuickPane". `scripts/trace/QuickPane.wprp` is a Windows Performance Recorder profile that records it with CPU and wait data.
- Property tests with FsCheck now cover how custom commands quote their values and which programs they refuse. FsCheck is in the test project only.
- `HotkeyService` takes an id and a purpose, so the keyboard navigation and quick switcher shortcuts register separately.
- The test suite now has 851 tests.
- Release `QuickPane.exe`: about 1.07 MB.

## Install

Download `QuickPane-3.13.0.0-x64-setup.exe` and run it. It installs for the current user, with no administrator rights. Over an existing QuickPane, including one installed by the original project's installer, it closes QuickPane, replaces the program, and updates the same Add/Remove Programs entry. Your settings, groups, and pins in `%APPDATA%\QuickPane` stay where they are.

The zip holds the same program, for replacing the files by hand instead:

1. Close QuickPane, and wait for it to finish: `Start-Process "$env:LOCALAPPDATA\QuickPane\QuickPane.exe" -ArgumentList '--exit' -Wait`
2. Keep a copy of the current `QuickPane.exe` in `%LOCALAPPDATA%\QuickPane`, so you can go back.
3. Unzip the download, and copy `QuickPane.exe` and `QuickPane.exe.config` into `%LOCALAPPDATA%\QuickPane`, replacing the files there.
4. Start `%LOCALAPPDATA%\QuickPane\QuickPane.exe` again.

`SHA256SUMS.txt` lists the SHA-256 hash of the installer, the zip, and each file inside the zip. The files are not code-signed, so Windows SmartScreen may warn before the installer first runs. This release also carries a GitHub build provenance attestation, which `gh attestation verify <file> -R prisant-labs/windows-explorer-quickpane` checks.
