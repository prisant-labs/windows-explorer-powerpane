# QuickPane 3.11.0.1 (fork)

QuickPane 3.11.0.1 is the first published release of the redesigned Settings window, which now looks and behaves like a page of the Windows 11 Settings app. It also adds a Quick actions section to the pane, a pane color choice, and a choice of monitor for the desktop dock, and it moves more slow work off Explorer's input queue. 3.11.0.0 was built as a draft on 2026-10-30 and never published: a desktop test of that draft found defects, all of which are fixed here, so this release carries everything 3.11.0.0 would have, and more.

## Why two passes of fixes

A desktop test of the 3.11.0.0 draft, on 2026-11-02, found eight defects, filed as #143 and #145 to #150 with #154 for Settings polish. All were fixed the same day. An adversarial review of those fixes by a second model (Codex) then found seven more weaknesses, C-01 to C-07. The six it rated high confidence were fixed as #159 and #161 to #165, and the seventh, #160, is open below. A new CI step, `scripts/check-rules.ps1` (#171), now fails a pull request that breaks the repository rules a compiler cannot see.

## Added

**A native Settings window.** `SettingsWindow` replaces the tabbed panel with a navigation pane, a search box, a breadcrumb for sub-pages such as a single profile or SSH connection, and a Mica backdrop on Windows 11. Windows 10, or a Mica failure, falls back to a standard window frame. Its cards and controls use a port of Microsoft's WPF Fluent theme, which stays in the Settings window's own resources, so the pane inside Explorer keeps its look. Nine pages replace the old tabs: Groups & profiles, Pane, Pane sections, Quick actions, Recent apps, Keyboard, SSH drives, Backup & restore, and About. Every control has an accessible name, and Tab and the arrow keys move through the window in reading order with a visible focus ring.

**Quick actions.** A pane section, off by default, with ten actions that can each be turned on or off and reordered from the new Quick actions page: copy the current folder's path (plain, quoted, forward-slash, WSL, or a Markdown link), add a new text file, Markdown file, or dated folder, or open the folder in Windows Terminal (falling back to PowerShell) or Visual Studio Code. A pinned folder's right-click menu offers the same actions against that folder. The section stays hidden in file dialogs and on the desktop dock, which have no current folder.

**Pane color.** A row of swatches on the Pane page tints the pane's background. Default matches Explorer's own color, and any other choice is your own opt-in, applied to every open pane at once.

**Dock display.** On a computer with more than one monitor, the Display row under the Desktop dock card picks the dock's monitor by name and resolution. "Primary display", the default, follows whichever monitor Windows calls primary. A specific choice is remembered by a stable device id, falls back to the primary display while that monitor is disconnected, and shows as "Saved display (not connected)" until you pick again.

## Changed

- **Settings layout.** Renaming a profile, reordering groups, moving a group to another profile, and reordering pane sections use named buttons instead of drag and drop. Pane sections rows are compact, single-line cards. About sits last in the navigation list, under Backup & restore.
- **The update check** runs only when the About page opens, or when you press "Check for updates" there, not every time Settings opens.
- **Background work.** Icons and drive details load in the background, and a finished icon updates only the rows that show it. Group, tab, and pin edits run in the background. A setting that does not change what the pane shows no longer rebuilds every pane. Settings changes are written to `settings.json` in the background, and QuickPane waits for the last write before it exits or makes a backup.
- **Backups** report "Backup failed" if the settings could not be written, instead of saving an older copy.

## Fixed

- **The desktop dock** reserves one strip at the monitor's edge and keeps it, instead of walking across the screen and squeezing maximized windows into a narrow strip (#145).
- **A beside pane** hides while the window it follows is dragged, including a keyboard move and a drag with swapped mouse buttons, and reappears in place when the drag ends (#147, #161).
- **Settings icons** are drawn in the theme's text color, so they show in dark mode, and the Pane page's icons are back after an edit had emptied them (#149, #134).
- **Dependent rows** under the Desktop dock and Profile tabs cards grey out while their card's switch is off. In a high-contrast theme, a greyed-out switch that is On keeps its outline (#150, #165).
- **Opening Settings** no longer logs a "Specified index is already in use" crash, and each profile shows its group count instead of "Loading groups…" (#143).
- **Settings search** puts keyboard focus on the Display box when you choose its result (#164).
- **Navigation focus** draws a ring around the item's own highlight, and each item's icon sits level with its label (#150, #154).
- **A crash after an Explorer restart.** QuickPane releases a pane's content as soon as the window it draws into loses the window above it, so Windows text input cannot trip over the dead handle. It checks whenever any window closes, whenever one of its own windows starts to move, and once a second (#148, #159).

## Still open

- **#148 (QuickPane exits after an Explorer restart)** stays open until a desktop run restarts Explorer and QuickPane keeps running. In Windows Sandbox, QuickPane survived an Explorer restart in the same process, and the guard released one pane whose host had gone. The crash itself has never been reproduced in the Sandbox.
- **#97 (how long Settings takes to open)** needs a desktop measurement. The Sandbox measured 420 to 490 ms against a 500 ms budget; a desktop measured 3,667 ms on the 3.11.0.0 draft, before later changes.
- **#160 (the dock after a monitor's scaling changes)** is unconfirmed. It needs two monitors at different scales.
- The display choice for the dock has only been tested with invented monitor lists, because the Sandbox has one monitor.

## For developers

- Settings code lives under `QuickPane/UI/Settings/`. Every page implements `SettingsPage`, and `SettingsPageBuildTests` builds each one with no window. A new test fails when a search entry's id has no focus target.
- `SettingsStore.Save()` returns before `settings.json` is written. Anything that reads the file from disk must call `Flush()` first.
- `scripts/check-rules.ps1` runs first in CI and in `scripts/test.ps1`. It fails on a `.cs` file missing from the csproj, a direct `SetWinEventHook` call, a raw private-use icon character, and `SettingsStore`'s default constructor in a test.
- The test suite grew from 171 tests in 3.10.0.11 to 543.
- Release `QuickPane.exe`: 689,152 bytes in 3.10.0.11, 1,013,248 bytes now, a growth of 324,096 bytes (316.5 KiB).

## Install

Download `QuickPane-3.11.0.1-x64-setup.exe` and run it. It installs for the current user, with no administrator rights. Over an existing QuickPane, including one installed by the original project's installer, it closes QuickPane, replaces the program, and updates the same Add/Remove Programs entry. Your settings, groups, and pins in `%APPDATA%\QuickPane` stay where they are.

The zip holds the same program, for replacing the files by hand instead:

1. Close QuickPane, and wait for it to finish: `Start-Process "$env:LOCALAPPDATA\QuickPane\QuickPane.exe" -ArgumentList '--exit' -Wait`
2. Keep a copy of the current `QuickPane.exe` in `%LOCALAPPDATA%\QuickPane`, so you can go back.
3. Unzip the download, and copy `QuickPane.exe` and `QuickPane.exe.config` into `%LOCALAPPDATA%\QuickPane`, replacing the files there.
4. Start `%LOCALAPPDATA%\QuickPane\QuickPane.exe` again.

`SHA256SUMS.txt` lists the SHA-256 hash of the installer, the zip, and each file inside the zip. The files are not code-signed, so Windows SmartScreen may warn before the installer first runs. This release also carries a GitHub build provenance attestation, which `gh attestation verify <file> -R prisant-labs/windows-explorer-quickpane` checks.
