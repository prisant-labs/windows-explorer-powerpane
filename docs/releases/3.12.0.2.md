# QuickPane 3.12.0.2 (fork)

QuickPane 3.12.0.2 makes one small change to the automatic update check. It changes nothing you will see. If you already run 3.12.0.1, you can update whenever suits you.

## Fixed

**The automatic update check no longer gives way to input ([#199](https://github.com/prisant-labs/windows-explorer-quickpane/issues/199)).** One Windows Sandbox run on 2026-11-04 saw the check wait until the cursor moved. A notice would have been delayed, not lost.

**This is a precaution, not a confirmed cure.** The delay was seen once, and its cause is inferred. Five Sandbox runs on 3.12.0.1 could not repeat it, with the cursor on the gear, over the pane, away from the pane, and left in place across a restart. The check ran 303 to 305 seconds after start in all five, and it is due at 300. This build ran at 303 seconds in the three positions it was tried in. If a late check appears again, this explanation was wrong.

## Still open

- **#148 (QuickPane exits after an Explorer restart)** stays open until a desktop run restarts Explorer and QuickPane keeps running.
- **#177 (dock height as a share of the monitor)** is the part of that issue still open.
- **#160 (the dock after a monitor's scaling changes)** is unconfirmed. It needs two monitors at different scales.
- **Testing.** The pin menu change from 3.12.0.1 was checked in Windows Sandbox and by unit tests only when this release was built. The change in this release was checked the same way.

## For developers

- `UpdateNotifier`'s timer runs at `DispatcherPriority.Normal`. `DispatcherTimer` defaults to `Background`, which WPF holds back while input is pending.
- Other timers at the default priority, in `ExplorerWatcher`, `ExplorerFollowerWatcher`, `RecentTracker`, and `AppBarHost`, have not been measured for this.
- The test suite still has 797 tests. Dispatcher priority cannot be exercised without a running dispatcher, so this change added none.
- Release `QuickPane.exe`: about 1.07 MB.

## Install

Download `QuickPane-3.12.0.2-x64-setup.exe` and run it. It installs for the current user, with no administrator rights. Over an existing QuickPane, including one installed by the original project's installer, it closes QuickPane, replaces the program, and updates the same Add/Remove Programs entry. Your settings, groups, and pins in `%APPDATA%QuickPane` stay where they are.

The zip holds the same program, for replacing the files by hand instead:

1. Close QuickPane, and wait for it to finish: `Start-Process "$env:LOCALAPPDATA\QuickPane\QuickPane.exe" -ArgumentList '--exit' -Wait`
2. Keep a copy of the current `QuickPane.exe` in `%LOCALAPPDATA%\QuickPane`, so you can go back.
3. Unzip the download, and copy `QuickPane.exe` and `QuickPane.exe.config` into `%LOCALAPPDATA%\QuickPane`, replacing the files there.
4. Start `%LOCALAPPDATA%\QuickPane\QuickPane.exe` again.

`SHA256SUMS.txt` lists the SHA-256 hash of the installer, the zip, and each file inside the zip. The files are not code-signed, so Windows SmartScreen may warn before the installer first runs. This release also carries a GitHub build provenance attestation, which `gh attestation verify <file> -R prisant-labs/windows-explorer-quickpane` checks.
