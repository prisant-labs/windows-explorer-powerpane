# QuickPane 3.12.0.0 (fork)

QuickPane 3.12.0.0 makes the pane's Quick actions section something you can extend, and it tells you when a new version exists. It adds 18 built-in actions, your own custom commands, and actions that work on the files selected in Explorer. Every new action starts off, so this update adds no rows to your pane.

| Change | What you will notice | Tracked in |
|---|---|---|

## Added

**Update notice.** QuickPane now asks GitHub for the latest release at most once a day, a few minutes after it starts. A newer version shows one notice for that version, an item in the tray menu, and a dot on About in Settings. It never downloads or installs anything, and the notice opens the release page in your browser. To stop the daily check, turn off "Check for updates automatically" on the About page. The README's privacy section lists exactly what the request sends.

**Ten more quick actions.** Copy folder name, Copy parent folder path, Copy as file URL, Copy PowerShell change-directory command, New PowerShell script, New README, New .gitignore, Open PowerShell here, Open WSL here, and Pin this folder. A new file never overwrites one that exists. Open WSL here appears only when a distribution is installed.

**Custom commands.** On the Quick actions settings page, give a command a name and a template, and it becomes a row you can turn on, reorder, edit, and delete. The template can use four placeholders:

| Placeholder | What it becomes |
|---|---|
| `{path}` | The first selected item, or the folder when nothing is selected |
| `{paths}` | Every selected item as its own argument, or the folder when nothing is selected |
| `{dir}` | The folder on screen, whatever is selected |
| `{name}` | The name of the first selected item, or of the folder |

Write `{{` and `}}` for literal braces. For example, `code {path}` opens the selected item in Visual Studio Code, and `"C:\Program Files\Git\git-bash.exe" --cd={dir}` opens Git Bash in the folder. The editor previews the expanded command as you type.

QuickPane splits the template first and then quotes each value, so a folder named `R&D notes` stays one argument. A program comes from PATH or a full path, starts directly in the folder, and never runs elevated. A placeholder is refused for a program that would read a folder name as code, such as `cmd`, `wsl`, `wt`, a batch file, PowerShell without `-File`, or `bash -c`. The same programs are fine with no placeholder. Commands in a restored backup arrive turned off, so a backup from someone else cannot run anything until you turn it on.

Quoting cannot make every program safe. A placeholder passed to an interpreter that is not on that list, such as `python -c`, is still read as that program chooses. A template is your own text, so use a placeholder only where the program treats it as a file name.

**Selection actions.** Eight new actions copy the selected names, paths, quoted paths, forward-slash paths, WSL paths, file URLs, or Markdown links, one per line, or open the selection in Visual Studio Code. A click with nothing selected says "Nothing selected" in the row and leaves the clipboard alone. "Copy path" and the other folder actions still act on the folder.

## Changed

- **A new quick action starts in its own default state.** Before this release, an action added by an update always started on. Reset to default restores the same state.

## Fixed

- **The width grip of a reserved desktop dock** can be dragged with a window maximized. The maximized window's invisible frame covered the whole grip, so the grip is wider on that dock (#185).

## Why this release waited for a review

An adversarial review of this work found three defects before any of it shipped. A template could name `cmd.exe` through `%COMSPEC%` and pass the shell check. A failed read of the Explorer selection looked like "nothing selected", so a custom command could act on the whole folder. Leaving the About page during a check used up the notice for a version nobody had seen. Checking those findings turned up a fourth defect: the notice for any `x.y.z.0` version, this one included, would have repeated every day. All four are fixed (#196). The review's other claim, that a batch file with no placeholder cannot start, was wrong, and a sandbox run started one.

## Still open

- **#148 (QuickPane exits after an Explorer restart)** stays open until a desktop run restarts Explorer and QuickPane keeps running.
- **#177 (dock height as a share of the monitor)** is the part of that issue still open.
- **#160 (the dock after a monitor's scaling changes)** is unconfirmed. It needs two monitors at different scales.
- **#199 (the automatic update check can run late)** was found after this release was published. In one Sandbox run, the check waited about five and a half minutes, until the cursor moved off the pane. The check still ran, so a notice is delayed and not lost. The cause is inferred from that one run.
- **Testing.** The changes here were checked in Windows Sandbox and by unit tests, not on a real desktop. The Sandbox did not cover these: the tray menu item, clicking the notice, Open WSL here running, the PowerShell 7 choice, Open selection in VS Code, a selection in a window with several tabs, the 1,000-item limit, or the dock grip at a scale other than 100%.

## For developers

- A new quick action is a `QuickActionLibrary` entry that passes `defaultEnabled: false`.
- `CustomCommandTemplate` holds the template rules, and its tests read each command line back through `CommandLineToArgvW`.
- `ExplorerNavigator.GetSelectedPaths` returns `SelectionReadStatus`, so a failed read is never mistaken for an empty selection.
- The test suite now has 773 tests.
- Release `QuickPane.exe`: about 1.06 MB.

## Install

Download `QuickPane-3.12.0.0-x64-setup.exe` and run it. It installs for the current user, with no administrator rights. Over an existing QuickPane, including one installed by the original project's installer, it closes QuickPane, replaces the program, and updates the same Add/Remove Programs entry. Your settings, groups, and pins in `%APPDATA%\QuickPane` stay where they are.

The zip holds the same program, for replacing the files by hand instead:

1. Close QuickPane, and wait for it to finish: `Start-Process "$env:LOCALAPPDATA\QuickPane\QuickPane.exe" -ArgumentList '--exit' -Wait`
2. Keep a copy of the current `QuickPane.exe` in `%LOCALAPPDATA%\QuickPane`, so you can go back.
3. Unzip the download, and copy `QuickPane.exe` and `QuickPane.exe.config` into `%LOCALAPPDATA%\QuickPane`, replacing the files there.
4. Start `%LOCALAPPDATA%\QuickPane\QuickPane.exe` again.

`SHA256SUMS.txt` lists the SHA-256 hash of the installer, the zip, and each file inside the zip. The files are not code-signed, so Windows SmartScreen may warn before the installer first runs. This release also carries a GitHub build provenance attestation, which `gh attestation verify <file> -R prisant-labs/windows-explorer-quickpane` checks.
