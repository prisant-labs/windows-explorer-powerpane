# Explorer PowerPane 4.1.0

PowerPane 4.1.0 makes adding things to the pane quicker. The right-click verb is now "Add to PowerPane". It works on files and drives as well as folders, lets you choose a tab, and skips items already there. Each group gains a **+** menu and **Sort pins**. Five new quick actions flip Explorer's own Show options, and they start off. The pane inside Open, Save As, and Select Folder dialogs gets several fixes. This is also the first release numbered with Semantic Versioning, so its tag is v4.1.0 rather than v4.1.0.0.

## Added

**Add to PowerPane on files and drives.** The right-click verb now appears on files and drives as well as on folders and folder backgrounds. Its window lets you choose a tab as well as a group, with "New group..." and "New tab..." entries, and it remembers the group and tab you used last. It is reachable by keyboard, and its controls are named for screen readers. Selecting several items and choosing the verb opens one window for all of them.

**Items already pinned are skipped.** Before you confirm, the verb's window says which items are already in the chosen tab, such as "1 of 3 items is already in this tab and will be skipped." When every item is already there, **Add** is turned off, so you choose another tab or cancel. A path matches whatever its letter case, a trailing backslash, or a forward slash.

**Sort pins.** A tab's right-click menu, and the header menu of a group with one tab, has a **Sort pins** submenu:

- **A to Z (keep sorted)** and **Recently added (keep sorted)** keep the tab in order by themselves, so a pin added by any route lands in its place.
- **Sort A to Z once** reorders the tab one time.
- **Manual order** turns keep-sorted off without moving anything.

A tab stays in manual order until you choose otherwise. Dropping an item at a line, or using Move up or Move down, puts a sorted tab back in manual order, with the order you left on screen.

**Explorer's Show options as quick actions.** Five quick actions flip Explorer's own **View > Show** options: **Show hidden items**, **Show file name extensions**, **Show item check boxes**, **Compact view**, and **Show navigation pane**. Each row's check box matches the setting, including a change made from Explorer's own menu. The settings apply to every Explorer window. The first four change open windows at once. The navigation pane changes in an open window when it next opens another folder. The five start off, under Settings > Quick actions.

## Changed

- **The verb's new name.** "Pin to PowerPane" is now "Add to PowerPane", because Explorer already uses "pin" for its own verbs. Inside the pane, pins are still called pins.
- **The + menu.** The **+** at the end of a group's tab strip, and the **+** in a one-tab group's header, open a menu to add a tab, a group below, a folder, or a file. Each entry names what it adds to. The group's right-click menu has the same entries, and a tab's right-click menu has the folder and file ones.
- **The new tab is selected.** After **Add tab** from a **+** menu or a group's menu, the new tab is the selected one, so a following **Add folder** or **Add file** goes into it.
- **Copy path follows the selection.** **Copy path** and the other folder copies use the items selected in Explorer, one per line, and the folder's path when nothing is selected. **Copy parent folder path** and the PowerShell change-directory copy still use the folder.
- **Dialogs that move the pane beside.** When an app's file dialog rearranges itself over the pane, the pane moves beside for that dialog only. The app's later dialogs move beside only after a second dialog does the same.
- **The icon** is the PowerPane logo without the title bar the 4.0.0.0 icon had.
- **A fixed download name.** Each release also carries the installer as `PowerPane-x64-setup.exe`, so [this link](https://github.com/prisant-labs/windows-explorer-powerpane/releases/latest/download/PowerPane-x64-setup.exe) always downloads the newest installer.
- **Semantic Versioning.** Releases are numbered as major, minor, and patch from this release on, with tags such as v4.1.0. The program's own version still has four parts, 4.1.0.0, because Windows requires them, and the About page shows it as 4.1.0. The update check compares the two forms correctly, so a copy of 4.0.0.1 is offered 4.1.0.

## Fixed

- **Select Folder dialogs.** Clicking a pin in a Select Folder dialog opened in another app now opens that folder. It used to choose the folder and close the dialog. A Select Folder dialog also no longer opens one pane width wider each time.
- **Idle redraws.** An open Open, Save As, or Select Folder dialog with the pane inside no longer redraws itself about once a second while nothing changes.
- **Resizing an Explorer window.** The pane stays up while you drag the window's border. It used to hide until you released.
- **Quick actions show a click.** A Quick actions row darkens when you click it or press Enter or Space on it.
- **Name boxes.** The box for a new tab, a new group, a rename, or a pin's path opens next to the control you used, on the pane's own monitor. It takes the pane's colours, including a chosen pane colour and a Windows contrast theme. An invalid name shows a message and turns off OK, where it used to be changed without a word.
- **The verb's window** opens fully on the monitor the pointer is on, and an item added from it lands in the tab you choose.

[CHANGELOG.md](https://github.com/prisant-labs/windows-explorer-powerpane/blob/main/CHANGELOG.md) has every entry in full.

## Still open

- **Testing.** The changes in this release were checked in Windows Sandbox with invented folders, and by unit tests. They have not yet run on a real desktop. Nobody has checked with a screen reader that the skipped-items note is announced, or measured the warning text under a contrast theme.
- **Light and dark switching.** In the Sandbox, after Windows switched between light and dark mode, the pane kept the old mode until PowerPane restarted, while the name box changed. This may be older than 4.1.0, and nobody has looked into it yet.
- **#148 (PowerPane exits after an Explorer restart)** stays open until a desktop run restarts Explorer and PowerPane keeps running.

## Install

Download `PowerPane-4.1.0-x64-setup.exe` and run it. `PowerPane-x64-setup.exe` is the same file under a name that never changes. It installs for the current user, with no administrator rights. Over an existing PowerPane, it closes PowerPane, replaces the program, and updates the same Add/Remove Programs entry. Your settings, groups, and pins in `%APPDATA%\PowerPane` stay where they are. While QuickPane is still installed, it stops and asks you to uninstall QuickPane first; the [4.0.0.0 release notes](https://github.com/prisant-labs/windows-explorer-powerpane/releases/tag/v4.0.0.0) describe moving across.

The zip holds the same program, for replacing the files by hand instead:

1. Close PowerPane, and wait for it to finish: `Start-Process "$env:LOCALAPPDATA\PowerPane\PowerPane.exe" -ArgumentList '--exit' -Wait`
2. Keep a copy of the current `PowerPane.exe` in `%LOCALAPPDATA%\PowerPane`, so you can go back.
3. Unzip the download, and copy `PowerPane.exe` and `PowerPane.exe.config` into `%LOCALAPPDATA%\PowerPane`, replacing the files there.
4. Start `%LOCALAPPDATA%\PowerPane\PowerPane.exe` again.

`SHA256SUMS.txt` lists the SHA-256 hash of the installer, the zip, and each file inside the zip. The files are not code-signed, so Windows SmartScreen may warn before the installer first runs. This release also carries a GitHub build provenance attestation, which `gh attestation verify <file> -R prisant-labs/windows-explorer-powerpane` checks.
